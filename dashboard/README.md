# dashboard/

This README only says where things are. The reasoning lives at [capas.digasnikas.com/documentation](https://capas.digasnikas.com/documentation).

Cloudflare Pages project `capas-dashboard` (`destination_dir: dashboard`), deployed at `capas.digasnikas.com`. Public, no login. Native ES modules, no build step.

| File | What |
|---|---|
| `index.html` | Public dashboard page (results, no login) |
| `dashboard.js` | Composition root: fetches `/api/stats` + `/api/matches`, owns the época dropdown and paper cards, hands the rest to `src/` |
| `src/common.js` | `API_URL`, `CLUB_META` (with dashboard colours), `MONTHS`, `joinList` |
| `src/calendar.js` | Calendar, barcode and "O suspeito" (match-day snub analysis) |
| `src/verdict.js` | Crowd and model verdict cards, the "onde discordam" browser |
| `src/averages.js` | "A capa média" section |
| `src/cover-modal.js` | Cover lightbox, single image or paging through AI diffs |
| `src/comments.js` | Google sign-in session and the day's comments |
| `dashboard.css` | Dashboard styles, a separate visual language from the app |
| `src/domain.js` | Club and paper display names, imported by `dashboard.js`, `search.js` and `similarities.js` |
| `dashboard.test.mjs` | Self-check: every id `dashboard.js` and `src/` read exists in `index.html`. Run `node dashboard/dashboard.test.mjs` |
| `avg/` | "A capa média" pixel means, generated by `scripts/avg_cover.py`. Static files; the section that reads them hides itself if absent. |
| `documentation.html` | This documentation site's renderer: hand-written markdown, no library |
| `documentation.js` | Its script. Kept out of the HTML so the CSP in `_headers` needs no inline scripts |
| `documentation/*.md` | The chapters it renders, one per topic |
| `similarities.html` | RAG match viewer: every cover with `ai_rag_covers`, next to the covers retrieval matched it to, one channel at a time (por texto / por imagem). Public, no login, like the rest of this project. Linked as "Parecidas" in every page's footer |
| `similarities.js` | Its script, same reason |
| `search.html` | Full-text search over `headlines` (D1 FTS5, `/api/search`). Public, no login. Not linked from anywhere in the UI |
| `search.js` | Its script, same reason |
