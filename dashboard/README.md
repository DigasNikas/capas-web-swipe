# dashboard/

This README only says where things are. The reasoning lives at [capas.digasnikas.com/documentation](https://capas.digasnikas.com/documentation).

Cloudflare Pages project `capas-dashboard` (`destination_dir: dashboard`), deployed at `capas.digasnikas.com`. Public, no login. Native ES modules, no build step.

| File | What |
|---|---|
| `index.html` | Public dashboard page (results, no login) |
| `dashboard.js` | Fetches `/api/stats` + `/api/matches`, renders everything |
| `dashboard.css` | Dashboard styles, a separate visual language from the app |
| `dashboard.test.mjs` | Self-check: every id `dashboard.js` reads exists in `index.html`. Run `node dashboard/dashboard.test.mjs` |
| `avg/` | "A capa média" pixel means, generated by `scripts/avg_cover.py`. Static files; the section that reads them hides itself if absent. |
| `documentation.html` | This documentation site's renderer: hand-written markdown, no library |
| `documentation/*.md` | The chapters it renders, one per topic |
| `similarities.html` | RAG match viewer: every cover with `ai_rag_covers`, next to the covers retrieval matched it to. Public, no login, like the rest of this project. Linked as "Parecidas" in every page's footer |
| `search.html` | Full-text search over `headlines` (D1 FTS5, `/api/search`). Public, no login. Not linked from anywhere in the UI |
