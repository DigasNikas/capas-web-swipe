Every cover with RAG matches recorded, next to the covers retrieval actually pulled for it. Retrieval runs two channels — the lead headline against the text index, the page against the image index — so this is where you see whether either finds real similarity or just same-newspaper layout. Only the matches that reached the prompt are recorded, not every cover each index proposed.
