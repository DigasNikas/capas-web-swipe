# landing/

This README is a map, not the manual — the reasoning lives at [capas.digasnikas.com/documentation](https://capas.digasnikas.com/documentation).

Cloudflare Pages project `capas-landing`, deployed at `capas.digasnikas.com`. Public, no login. Native ES modules, no build step.

| File | What |
|---|---|
| `index.html` | Public landing page (results, no login) |
| `landing.js` | Fetches `/api/stats` + `/api/matches`, renders everything |
| `landing.css` | Landing page styles — separate visual language from the app |
| `landing.test.mjs` | Self-check: every id `landing.js` reads exists in `index.html` — `node landing/landing.test.mjs` |
| `avg/` | "A capa média" — pixel means, generated by `scripts/avg_cover.py`. Static files; the section that reads them hides itself if absent. |
| `documentation.html` | This documentation site's renderer — hand-written markdown, no library |
| `documentation/*.md` | The chapters it renders, one per topic |
